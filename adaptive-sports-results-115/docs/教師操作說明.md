# 教師操作說明（3 分鐘版）

網址：`〈正式網址〉/staff`（管理者會另外傳給你）。手機、平板、電腦都可以用。

## 登入（不用帳號、不用密碼）
1. 管理者會給你一組 **6 位數認證碼**，或一個登入連結／QR Code。
2. 點連結或掃 QR 就直接登入；或打開 `〈正式網址〉/staff` 輸入認證碼。
3. 忘記認證碼？找管理者查看或重新產生。

## 成績輸入人員：5 個步驟
1. 登入後會看到**我負責的項目**（依國小組／國中組分列），點要輸入的項目。
2. 用「快速新增：選學校」選出得名學校，系統自動填下一個名次；也可以直接改名次數字。
3. 填成績（可留空）。**名次以裁判核定為準**，系統不會自動排序。
   - 並列：兩校同名次時，系統會亮黃色，請把那幾列的「並列」都勾起來。
   - 沙包投擲賽是單淘汰，直接填名次即可。
4. 按「**儲存草稿**」。畫面下方會顯示：`儲存中… / 已儲存 時間 / 儲存失敗 / 離線：本機草稿尚未同步`。
   - 沒網路時資料會留在你的手機，恢復連線後自動送出，不會重複。
   - 若跳出「偵測到衝突」，代表別人也改了這張表；請選「載入伺服器版本」看一下再決定。
5. 確認無誤按「**送複核**」。送出後不能再改；需要改請請複核人員退回。

## 複核人員
1. 登入 → 「待複核」→ 點項目，畫面上就是**公開頁會長的樣子**（國小 8 名、國中 3 名）。
2. 正確 → 「確認發布」，公開頁 20 秒內自動更新。
3. 有誤 → 「退回修正」並寫原因，輸入人員會看到。
4. 已公布後發現錯誤：任何人按「建立修訂草稿」→ 修改 → 送複核 → 發布後公開頁才換新版；期間舊版繼續顯示。

## 公開成績頁（給家長與各校）
- 網址 `〈正式網址〉`，免登入。上方選國小組／國中組、項目，可搜尋學校。
- 右上角「QR Code」可投影或列印給大家掃；「列印」為列印友善版。
- 沒有公布的項目會顯示「成績尚未公告」。

## 小提醒

- 手機請直式操作；按鈕都夠大，不用縮放。
- 有問題找特教組：竹東國中 5961207 分機 605。
