# 後台部署說明（只做一次，約 5 分鐘）

系統分兩部分：網站（GitHub Pages，已上線）＋ 後台（您 Google 帳號裡的 Apps Script，免費、不休眠、不用主機）。
後台把成績存進您雲端硬碟「115適應體育」資料夾裡的「**115第23屆適應體育 成績資料庫**」試算表。

## 步驟

1. 打開試算表「115第23屆適應體育 成績資料庫」。
2. 上方選單 **擴充功能 → Apps Script**，會開新分頁，畫面中間有一段 `function myFunction() {}`。
3. 全選那段程式刪掉，把 `Code.gs` 的內容整段貼上（雲端硬碟同一資料夾有「Code.gs.txt」可複製，或到 GitHub 的 backend/Code.gs）。
4. 按上方磁碟片圖示（儲存）。
5. 上方「執行」左邊的函式下拉選單選 **setup**，按 **執行**。第一次會跳出授權：
   選您的 Google 帳號 → 若出現「Google 尚未驗證這個應用程式」按 **進階 → 前往（不安全）** → **允許**。
   執行完，回到試算表會多出「成績、學校、人員、設定、紀錄」五個分頁；「人員」分頁裡就是認證碼。
6. 右上 **部署 → 新增部署作業** → 左邊齒輪選 **網頁應用程式** →
   說明隨便填、執行身分 **我**、誰可以存取 **任何人** → **部署**。
7. 複製「網頁應用程式」的網址（開頭是 https://script.google.com/macros/s/…/exec），傳給我，我把它填進網站。

之後如果改了程式碼，要 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署**，網址不變。

## 管理

- **認證碼**：試算表「人員」分頁，可直接改名稱、改碼、新增列；角色 admin 可改公告，entry 只能登打。
- **學校名單**：「學校」分頁，115 年報名截止後依報名表增減，打 V 表示該組別有參賽。
- **成績**：「成績」分頁是資料本體，每列一個名次；「公布」欄有 V 才會顯示在公開頁。想手動改也可以，網頁 20 秒內跟著變。
- **紀錄**：每次儲存都記錄時間、人員、修改前後內容。
